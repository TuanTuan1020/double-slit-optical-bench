实验手册

从条纹到光子，模型如何成立

这台虚拟光学台只做一件事：把同一组夫琅禾费公式，连续地映射到屏幕、读数和光子探测点上。下面的假设、步骤与边界，决定了这些数字何时可信。

物理模型

波长为 λ 的相干平面波垂直照明两条等宽、等强、相距 d 的狭缝。远场屏幕上，双缝干涉因子与单缝衍射包络相乘：

I(θ) I0 = sinc2(β) · cos2(α)

β = πa sinθ / λ，α = πd sinθ / λ。

屏幕坐标使用精确几何 y = L tanθ、sinθ = y/√(y² + L²)，而不是把 sinθ 直接当作 θ。相邻明纹的小角近似为 Δy ≈ λL/d。

当 m·a/d 为整数时，干涉极大与单缝衍射极小重合，出现缺级；例如 d/a 为整数时，m = n(d/a) 级缺级。屏上可见级次由视场边缘的 sinθ 决定。

远场判据：NF = (d + a)²/(λL) ≪ 1。当前参数范围保证 NF ≤ 0.09。

实验步骤

  1. 设定光源。选择单色光，把波长调到 632.8 nm；或切换到白光，观察中央白色、边缘彩色的图样。
  2. 设定双缝。取 d = 0.120 mm、a = 0.030 mm，保持 a < d。注意 d/a = 4 时会出现 ±4 级缺级。
  3. 设定屏距与视场。取 L = 2.00 m、视场 100 mm，让中央包络和 ±4 级缺级同时进入屏幕。
  4. 读取条纹。拖动青色探测线到中央明纹、第一级明纹和第一级暗纹，记录 y、Δ 与 I/I₀。
  5. 验证间距。比较相邻明纹间距与 λL/d；改变 d 或 L，观察条纹如何疏密变化。
  6. 寻找缺级。保持 d/a 为整数，观察 ±4 级位置光强接近零；把 a 调离整数比，缺级消失。
  7. 单光子累积。切换到单光子，逐个发射或自动累积。少量光子是随机点，计数增加后逐渐显出理论曲线。
  8. 记录与导出。点击“记录当前”保存一组参数；用 CSV 导出记录或完整强度曲线。

误差与边界

  • 理想相干。模型假设两缝被同一相干平面波等幅照明。真实激光有有限线宽和光束轮廓，条纹对比度会下降。
  • 远场近似。公式只在 NF ≪ 1 时成立。界面把参数限制在 NF ≤ 0.09；超出这个范围应使用菲涅耳衍射。
  • 标量衍射。忽略偏振与缝壁的近场耦合；缝宽远大于波长时成立。
  • 屏幕线性。条纹亮度按相对强度 I/I₀ 显示，不表示绝对辐照度；显示端做了 sRGB 编码。
  • 白光颜色。用 6500 K 黑体谱与 CIE 1931 2° 观察者计算，中央白平衡；颜色是显示近似，不是光谱仪读数。
  • 光子统计。每个探测点独立按归一化强度抽样，忽略暗计数、死时间和探测器效率。
